# Аналіз попередження Майкла Б'юррі про обвал біткоїна

## Огляд проекту

Цей репозиторій містить детальний аналіз попередження відомого інвестора Майкла Б'юррі про можливий обвал біткоїна та практичні інструменти для відстеження інвестиційних можливостей.

## Зміст

### 📄 Документація

1. **bitcoin_analysis_investment_opportunities.md** - Детальний аналіз статті Bloomberg з виявленням можливих вигод:
   - Резюме попередження Б'юррі
   - 6 конкретних інвестиційних можливостей
   - Стратегії управління ризиками
   - Сигнали для дій
   - Таймлайн можливих подій
   - Інструменти для моніторингу

2. **GOLD_INVESTMENT_REPORT_UA.md** - Повний аналіз прибутковості золотих злитків:
   - Детальний розрахунок прибутку (+1.89% чистими)
   - Структура витрат (комісії банків 6%, податки 19.5%)
   - Порівняння з альтернативами (депозит, біткоїн, S&P 500)
   - Розрахунки для гривні
   - Альтернативні способи інвестування в золото
   - Практичні рекомендації та чеклисти

3. **investment_comparison.md** - Порівняльна таблиця всіх інвестицій:
   - Детальне порівняння 8 активів
   - Рейтинг за прибутковістю та ризиком
   - Візуальні таблиці результатів
   - Уроки з досвіду
   - Оптимальні портфелі для різних профілів

4. **QUICK_ACTION_GUIDE.md** - Швидкий посібник дій з конкретними кроками

### 🐍 Python скрипти

1. **bitcoin_tracker.py** - Автоматизований інструмент для моніторингу біткоїна:
   - Відстеження поточної ціни BTC в реальному часі
   - Аналіз критичних рівнів за методологією Б'юррі
   - Індекс страху та жадібності
   - Автоматичні рекомендації для інвестування
   - Розрахунок потенційного прибутку
   - Режим постійного моніторингу

2. **gold_investment_calculator.py** - Калькулятор прибутку від золотих злитків:
   - Реальні історичні ціни золота
   - Розрахунок з урахуванням комісій банків (6%)
   - Розрахунок з урахуванням податків України (19.5%)
   - Порівняння різних сум інвестицій
   - Порівняння з альтернативними інвестиціями

### Використання

#### Bitcoin Tracker - Моніторинг біткоїна:

```bash

python bitcoin_tracker.py

# Постійний моніторинг (кожні 5 хвилин)
python bitcoin_tracker.py --monitor 300

# Постійний моніторинг (кожну хвилину)
python bitcoin_tracker.py --monitor 60
```

#### Gold Calculator - Аналіз інвестицій у золото:

```bash
# Аналіз для типових сум
python gold_investment_calculator.py

# Аналіз для конкретної суми
python gold_investment_calculator.py 15000

# Приклади:
python gold_investment_calculator.py 10000  # $10,000
python gold_investment_calculator.py 50000  # $50,000
```

## 📝 Про Майкла Б'юррі

Майкл Б'юррі - американський інвестор та засновник хедж-фонду Scion Asset Management. Він прославився тим, що передбачив фінансову кризу 2008 року та заробив мільярди доларів на парі проти ринку нерухомості США. Його історія описана в книзі "The Big Short" та однойменному фільмі.

Попередження Б'юррі заслуговують на увагу через його підтверджений послужний список передбачення великих ринкових подій.
